# M1-D3 Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the wallet a Settings screen with view seed, biometrics, auto-lock timeout, theme, assets on/off, about and delete wallet.

**Architecture:** Three small typed stores over the existing `KeyValueStore`, following the `BackupStatusStore` pattern already in `lib/data/storage/`. A `SettingsCubit` backs the page only; the consumers (`LockCubit`, `PortfolioBloc`, `MaterialApp`) read their own store directly, so no god-object sits between unrelated features. One module owns the per-wallet key prefixes so delete-wallet can sweep them.

**Tech Stack:** Flutter 3.41.4 (fvm-pinned), flutter_bloc, go_router, flutter_secure_storage, `gen_l10n` ARB, `komodo_defi_sdk` (fork `digibyte/main`), `package_info_plus` (new dependency, Task 6).

**Spec:** `docs/superpowers/specs/2026-10-10-m1d3-settings-design.md`

## Global Constraints

- Flutter ≥ 3.35, Dart SDK `>=3.9.0 <4.0.0`. Build with `.fvm/flutter_sdk/bin/flutter`, never a bare `flutter` (the system one is Dart 3.7 and fails dependency resolution).
- `flutter analyze` must stay clean; the repo uses `very_good_analysis` 10.2.0.
- Every user-facing string goes in `lib/l10n/arb/app_en.arb` and is read through `context.l10n`. No literal UI strings.
- Every interactive row carries a `Tagged` semantics identifier, `settings.<item>`, because the acceptance tooling drives the app by identifier, not by text.
- Never log, print or dump a seed, a password or a `bio_pw_*` value. Screens showing a seed set `FLAG_SECURE`.
- Per-wallet storage keys are `<prefix>_<walletName>`, matching the existing `backup_pending_<wallet>` and `bio_pw_<wallet>`.
- 2 min stays the auto-lock default (`SecurityDefaults.autoLockTimeout`); the store falls back to it.
- DGB is pinned: it is always first and can never be switched off (`Brand.listedAssets` is `['DGB', 'BTC', 'LTC']`).

## Review Focus

These are the input classes the spec implies but that no task's happy path exercises. Each line's test is added to the task that owns the code.

1. **A per-wallet setting written for wallet A must never be read for wallet B.** Two wallets with different auto-lock values must not bleed into each other — Task 1 owns the key construction and tests it.
2. **A deleted wallet's keys must not come back when a new wallet reuses its name.** Creating `legacy3` again after deleting `legacy3` must start from defaults, not inherit the old auto-lock, asset or biometric state — Task 9.
3. **A stored value that is corrupt or from a future version must not crash the app.** `autolock_<wallet>` holding `"banana"`, or `assets_off_<wallet>` naming a ticker that no longer exists, must fall back to the default and keep going — Tasks 3 and 4.
4. **Changing auto-lock must apply to the session already running**, not only after the next sign-in; and shortening it below the time already spent in the background must lock on the next resume — Task 3.
5. **Switching an asset off while it is still activating** must not leave a half-activated coin or a stuck `activating` row — Task 5.

```dart
import 'package:digibyte_dex/data/storage/key_value_store.dart';

/// Every storage key that belongs to one wallet, in one place.
///
/// Delete-wallet sweeps [allPrefixes] rather than naming keys at the call
/// site, so a setting added later cannot be orphaned by a deletion
/// (spec §3).
abstract final class WalletScopedKeys {
  /// Auto-lock timeout, in whole seconds.
  static const autoLock = 'autolock';

  /// Comma-separated tickers the user switched off.
  static const assetsOff = 'assets_off';

  /// Whether a created wallet still owes its seed backup.
  static const backupPending = 'backup_pending';

  /// The biometric entries, in the `dgbdex_bio` namespace.
  static const biometricPassword = 'bio_pw';
  static const biometricMarker = 'bio_on';

  static const allPrefixes = <String>[
    autoLock,
    assetsOff,
    backupPending,
    biometricPassword,
    biometricMarker,
  ];

  static String keyFor(String prefix, String wallet) => '${prefix}_$wallet';

  /// Deletes every per-wallet key for [wallet] from [store]. Keys that are
  /// absent are skipped; app-wide keys are untouched.
  static Future<void> sweep(KeyValueStore store, String wallet) async {
    for (final prefix in allPrefixes) {
      await store.delete(keyFor(prefix, wallet));
    }
  }
}
```

```dart
import 'dart:async';

import 'package:digibyte_dex/data/storage/key_value_store.dart';
import 'package:flutter/material.dart' show ThemeMode;

/// The app-wide theme mode (spec §3). App-wide, not per wallet: it is
/// about the device, and the sign-in page needs it before any wallet is
/// chosen.
class ThemeStore {
  ThemeStore(this._store);

  final KeyValueStore _store;
  final _changes = StreamController<ThemeMode>.broadcast();

  static const _key = 'theme_mode';

  /// Emits on every [write], so the root MaterialApp restyles at once.
  Stream<ThemeMode> get changes => _changes.stream;

  Future<ThemeMode> read() async => switch (await _store.read(_key)) {
    'light' => ThemeMode.light,
    'dark' => ThemeMode.dark,
    // Anything else, including a value a later version wrote, is the
    // default rather than a crash.
    _ => ThemeMode.system,
  };

  Future<void> write(ThemeMode mode) async {
    await _store.write(_key, mode.name);
    _changes.add(mode);
  }

  Future<void> dispose() => _changes.close();
}
```

```dart
import 'package:digibyte_dex/config/security_defaults.dart';
import 'package:digibyte_dex/data/storage/key_value_store.dart';
import 'package:digibyte_dex/data/storage/wallet_scoped_keys.dart';

/// How long the app may sit in the background before it locks, per wallet
/// (spec §2 decision 4 and §3). There is deliberately no "never": a funded
/// wallet must not stay unlocked indefinitely.
class AutoLockStore {
  AutoLockStore(this._store);

  final KeyValueStore _store;

  /// Offered in the settings list, shortest first. Zero means lock as soon
  /// as the app leaves the foreground.
  static const choices = <Duration>[
    Duration.zero,
    Duration(minutes: 1),
    Duration(minutes: 2),
    Duration(minutes: 5),
    Duration(minutes: 15),
  ];

  Future<Duration> read(String wallet) async {
    final raw = await _store.read(
      WalletScopedKeys.keyFor(WalletScopedKeys.autoLock, wallet),
    );
    final seconds = int.tryParse(raw ?? '');
    if (seconds == null) return SecurityDefaults.autoLockTimeout;
    final stored = Duration(seconds: seconds);
    // A value this version does not offer (an older or newer build, or a
    // corrupt entry) is not trusted into the lock path.
    return choices.contains(stored)
        ? stored
        : SecurityDefaults.autoLockTimeout;
  }

  Future<void> write(String wallet, Duration timeout) => _store.write(
    WalletScopedKeys.keyFor(WalletScopedKeys.autoLock, wallet),
    '${timeout.inSeconds}',
  );
}
```

```dart
import 'package:digibyte_dex/config/brand.dart';
import 'package:digibyte_dex/data/storage/key_value_store.dart';
import 'package:digibyte_dex/data/storage/wallet_scoped_keys.dart';

/// Which assets the wallet shows and activates (spec §5.4).
///
/// The *off* list is persisted, not the on list, so an asset added in a
/// later release is on by default instead of silently missing.
class EnabledAssetsStore {
  EnabledAssetsStore(this._store);

  final KeyValueStore _store;

  /// Always on, always first: the app is a DigiByte wallet.
  static const pinned = 'DGB';

  Future<Set<String>> disabled(String wallet) async {
    final raw = await _store.read(
      WalletScopedKeys.keyFor(WalletScopedKeys.assetsOff, wallet),
    );
    if (raw == null || raw.isEmpty) return const {};
    return raw
        .split(',')
        .where(Brand.listedAssets.contains) // drops blanks and delisted
        .where((ticker) => ticker != pinned)
        .toSet();
  }

  Future<bool> isEnabled(String wallet, String ticker) async =>
      !(await disabled(wallet)).contains(ticker);

  Future<void> setEnabled(
    String wallet,
    String ticker, {
    required bool enabled,
  }) async {
    if (ticker == pinned) return; // never switchable
    final next = {...await disabled(wallet)};
    if (enabled) {
      next.remove(ticker);
    } else {
      next.add(ticker);
    }
    await _store.write(
      WalletScopedKeys.keyFor(WalletScopedKeys.assetsOff, wallet),
      next.join(','),
    );
  }
}
```
